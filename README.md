# Revit-tools

点击 **V1 → 楼板上色与图例**，更新共用同一 View Template 的楼层平面颜色和各层楼板图例。面向 Revit 2023 与 pyRevit。首次安装请阅读仓库里的 `INSTALL_zh.md`。

## 使用

1. 将仓库下载到固定目录，运行 `Install.ps1`，然后在 Revit 中点击 **pyRevit → Reload**。
2. 打开楼层平面，点击 **楼板上色与图例**。首次使用选择已有的 `SLAB LEGEND` 详图作为格式参考；只有一个符合条件的图例时自动选择。
3. 图例出现在 **Drafting Views** 中，名称以 **V1 SLAB** 开头。原图例所在图纸同时包含对应平面时，在原位置显示更新后的图例，原详图保留作格式参考。
4. 其他图纸：打开 Sheet，按住 **Shift** 点击按钮，选择 **放到当前 Sheet**，再点击放置位置。
5. 修改楼板或视图后，再点击一次刷新。重复更新沿用同一图例视图，保留图纸上的位置。

## 统计规则

- 只纳入当前项目中、相关平面可见范围内，单块面积 **≥20㎡**、顶面水平且具有有效 **Elevation at Top** 的 Floor。斜坡、阶梯顶面、缺失标高和小板不列入。
- 按顶标高分组，从实际楼板读取厚度，去重后从小到大排列，例如 `200/400 mm`。标高显示为米，保留三位小数。
- 直接复用原详图的字体、字号、列宽、行高、线型、柱/梁行和色块类型。只按实际分组数量增减楼板行，不缩放表格。
- 使用原图例的颜色。相同标高保持同色，同一平面内不复用颜色；如果颜色确实不够，停止更新并提示。
- 通过 View Filters 上色。为准确排除几何上倾斜或过小的板，过滤器使用按标高分组的楼板选择集合；不是逐个元素的图形覆盖。增删楼板、改变标高或加入新平面后，需要再点按钮刷新集合。
- 只新增或更新工具自己的楼板过滤器，不移除再添加其他过滤器，也不改它们的颜色、显示开关、启用状态或彼此顺序。Wall 建的 Kerb、梁、柱等保持原设置，模板其他设置不修改。旧的仅针对 Floors 且以 `Floor SFL ` 开头的过滤器从该模板移除，但不删除其定义；同时包含其他类别的过滤器保留。
- 按钮不改变楼板几何、标高、厚度，不自动保存或同步项目。可用 Revit Undo 撤销本次更新。

## 检查

按住 Shift 点击按钮，选择 **只检查，不修改模型**，可试运行后自动回滚。操作记录只保存在本机，不会上传模型或图纸。

本工具不处理链接模型里的楼板。Revit 的视图收集结果不等同于逐像素遮挡检测：被其他构件完全遮挡但仍属于视图可见范围的楼板可能被统计。

开发检查：`python -m unittest discover -s tests -v`。`tests/revit_verify.py` 供 Revit 内验证重复刷新、过滤器成员及原图例保留，验证结束会回滚。
